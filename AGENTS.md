# App Store Connect

For App Store Connect tasks, use the installed `asc` skills and the command reference in [ASC.md](ASC.md).

Yah's current Xcode bundle identifiers are `local.yah.ios` for iOS, `local.yah.ios.keyboard` for the keyboard extension, and `local.yah.mac` for macOS. Verify the relevant App Store Connect app record before using an app ID in a workflow.
