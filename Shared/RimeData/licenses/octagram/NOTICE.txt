yah-octagram-zh-hans.gram is a modification of zh-hans-t-essay-bgw.gram

Original data and its licence (pinned revision)
https://github.com/lotem/rime-octagram-data/tree/f8ce3b534733e489a8470a7c2adf5a154e8ea069
https://raw.githubusercontent.com/lotem/rime-octagram-data/f8ce3b534733e489a8470a7c2adf5a154e8ea069/zh-hans-t-essay-bgw.gram

Yah retains all 112603 entries whose original encoded score is at least
110000 and preserves their original scores. The resulting model occupies
1227820 bytes. The conversion source accompanies this notice. The required
Darts-clone header is available from the following revision.
https://github.com/s-yata/darts-clone/tree/87b71afd6cf784953e3c08f24c64203397f3b724

In the Yah source tree, run Tools/Octagram/rebuild.sh. To rebuild directly,
place the original model, saved as upstream.gram, and the pinned include/darts.h
in the same directory as prune-word-bigrams.cpp, then run these commands.
c++ -std=c++17 -O2 -I . prune-word-bigrams.cpp -o prune
./prune upstream.gram yah-octagram-zh-hans.gram
